## Findings

### [SECURITY-01] Upgrade Next.js past current high advisories

- **Evidence**: `package.json:42` pins `next` to `16.2.4`; `pnpm audit --prod --audit-level high` reports high advisories patched by `16.2.5` and `16.2.6`.
- **Impact**: The repo should not be publicly deployed or used as a hiring demo on a framework version with current high advisories when the patch appears to be a same-minor upgrade.
- **Effort**: S.
- **Risk**: LOW; same-minor patch, verified by build/test/lint.
- **Confidence**: HIGH.

### [SECURITY-02] Lock provider and remote-asset boundaries before public demo

- **Evidence**: `src/app/api/fal/proxy/route.ts:5` and `src/app/api/fal/proxy/[...path]/route.ts:5` call `createRouteHandler()` with no endpoint allowlist or auth check; `pnpm build` prints the fal proxy warnings about all endpoints and unauthenticated requests. `src/app/api/assets/persist/route.ts:7-10` accepts any URL and kind; `src/lib/storage/persist-remote.ts:14-31` fetches the URL and writes it with no host allowlist, content-type allowlist, or size cap.
- **Impact**: A public deployment could turn the demo into an unauthenticated provider-spend proxy and arbitrary remote downloader.
- **Effort**: M.
- **Risk**: MED; provider-backed local flows depend on these routes, so the fix needs local tests and a clear demo mode boundary.
- **Confidence**: HIGH.

### [DIRECTION-01] Add a public-safe portfolio demo mode

- **Evidence**: The app is a real local creative tool with graph persistence (`src/lib/db/repositories/projects.ts:96-151`), provider nodes (`src/features/canvas/nodes/PromptNode.tsx:96-195`, `src/features/canvas/nodes/MeshNode.tsx:61-172`, `src/features/canvas/nodes/VideoNode.tsx:61-158`), and local asset storage. Current portfolio proof uses a fake-data screenshot, but the live app has no dedicated fixture route that proves the product without provider keys or private media.
- **Impact**: A recruiter-safe demo route would turn Carvingen from a static case study into an inspectable product surface without exposing real prompts, generated outputs, SQLite state, or fal spend.
- **Effort**: M.
- **Risk**: MED; demo state must stay isolated from the real workspace and avoid accidentally enabling provider calls.
- **Confidence**: HIGH.
